# Session Notes — July 28, 2026

## Advanced Theme Settings

Added a full per-object opacity + glass blur system.

**`src/theme/AppSettingsContext.tsx`**
- Added `perObjectOpacity: Record<string, number>` and `perObjectGlassBlur: Record<string, boolean>` to app settings state
- Added `setObjectOpacity(id, value)`, `resetObjectOpacity(id)`, `setObjectGlassBlur(id, enabled)` setters
- Both persist to AsyncStorage (`ripple_per_object_opacity`, `ripple_per_object_glass_blur`)

**`src/components/ShadowCard.tsx`**
- Per-object opacity now takes priority over global `cardOpacity` when a `cardId` or `tileId` is passed

**`src/screens/settings/AppearanceSettingsScreen.tsx`**
- Added **Advanced** collapsible menu inside the Theme section (sits below the palette groups)
- Each card/tile in the app gets its own expandable row showing: opacity slider, glass blur toggle (labelled "Requires next build"), and a Reset to Global button
- Rows are grouped by screen: Home, Health, Meals, Life, Finance, Med/Cycle
- Removed `LayoutAnimation` and `overflow: hidden` from the expand/collapse (was blocking touch events on Android)
- Used a dedicated `advCard` style without overflow clipping

**Wired `cardId` props on key ShadowCards** so sliders visually take effect:
- `HealthScreen`: `glucose_card` (sleep_card was already wired)
- `MealsScreen`: `meal_log`, `food_report`, `glucose_panel`
- `LifeScreen`: `books_card`, `hobbies_card`, `mood_log_card`
- `FinanceScreen`: `spending_total`, `spending_breakdown`

Glass blur is saved to AsyncStorage now and will activate after the next EAS build when `expo-glass-effect` is enabled.
